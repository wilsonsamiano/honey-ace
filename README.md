# Honey Ace

A cute TwinBee-style shoot ’em up. Fly Bumble, pick Easy / Normal / Hard, level firepower, hull, rockets, and call a Twin Bee.

## Play

```bash
npm install
npm run dev
```

Open the URL the script prints (port 8080). Touch or mouse to fly. Auto-fire. Esc or P pauses.

## Build

```bash
npm run build
npm run preview
```

PWA-ready: install from the browser for offline play.
